![version](https://img.shields.io/badge/version-1.0.0-blue)
![KOMPAS-3D](https://img.shields.io/badge/КОМПАС--3D-v22-green)

**kompas-mcp** — MCP-сервер для КОМПАС-3D v22: 75 инструментов, которыми модель
(Claude Code, Claude Desktop и другие MCP-клиенты) строит чертежи по ЕСКД, 3D-детали
и сборки, зубчатые и червячные передачи, пружины, крепёж по ГОСТ и сборочные чертежи
со спецификацией. В комплекте — копилот «Давинчи»: чат прямо в окне КОМПАСа.

**Документация:** [руководство оператора](docs/operator-guide.md) ·
[справочник по классам](docs/classes.md) ·
[справочник инструментов](docs/tools.md)

## Возможности

**Чертежи по ЕСКД**
- Примитивы, линейные, диаметральные, радиальные и угловые размеры, цепочки
  размеров, штриховка, шероховатость, линии разреза, технические требования,
  основная надпись, экспорт в DXF и PNG.
- Готовые чертежи деталей передач: цилиндрическое колесо (ГОСТ 2.402/2.403),
  коническое колесо (ГОСТ 2.405), червяк и червячное колесо (ГОСТ 2.406),
  пружина сжатия с диаграммой испытаний (ГОСТ 2.401). Таблица параметров —
  в правом верхнем углу, масштаб выбирается из ряда ГОСТ 2.302 по размеру листа.

**3D-модели**
- Детали из эскизов: выдавливание, вращение, вырезы, отверстия, фаски,
  скругления; материал и масса; рендер в PNG в аксонометрии и шести
  стандартных видах — в том числе при скрытом окне КОМПАСа.
- Передачи: цилиндрическое колесо с эвольвентным профилем, коническое колесо
  с зубьями, сходящимися к вершине конуса, архимедов червяк (1–4 захода,
  правый или левый), червячное колесо с горловиной и наклоном зубьев.
  Сборки пар в зацеплении — цилиндрической, конической и червячной.
- Пружины сжатия (поджатые и сошлифованные концы, высота как на чертеже)
  и растяжения (с зацепами).
- Стандартные изделия по таблицам ГОСТ: болты, гайки, шайбы М6–М48,
  шпильки, штифты цилиндрические и конические, шарикоподшипники 201–215
  и 305–314.

**Сборки и сборочный чертёж**
- Вставка и расстановка компонентов, сборочный чертёж по файлу сборки:
  ассоциативные виды в проекционной связи, габаритные размеры, позиции
  линиями-выносками (одинаковые детали — одна позиция) и спецификация
  по ГОСТ 2.106 тем же списком позиций.

**Расчёты**
- Геометрия передач (ГОСТ 16532, 19624, 19036), допуски и посадки ЕСДП
  (ГОСТ 25346/25347), моменты инерции сечений, справочник материалов.
- Проверочные расчёты: прямозубая передача по ГОСТ 21354 (контакт, изгиб,
  отклонение передаточного числа), червячная передача (скорость скольжения,
  КПД, самоторможение, прочность венца), пружина по ГОСТ 13765 (силы, высоты,
  напряжения, устойчивость). Результат возвращается и готовыми строками
  технических требований для чертежа.

**Копилот «Давинчи»**
- Библиотека КОМПАСа с меню и окном чата: запрос обычным языком выполняется
  в открытом КОМПАСе пользователя, документы появляются у него на экране.

## Пример

Запрос к модели:

> Сделай червячную передачу m=5, z1=2, q=10, z2=40 с отверстием колеса 40.
> Проверь её при моменте 400 Н·м на колесе и 1450 об/мин, выпусти чертежи
> червяка и колеса с результатом проверки в технических требованиях и
> сборочный чертёж со спецификацией.

Модель вызывает `worm_check`, `worm_drawing`, `worm_wheel_drawing` (строки
`tech` из проверки — в технические требования), `worm_pair` и
`assembly_drawing`. Результаты — в папке `mcp-out` рядом с сервером:
чертежи `.cdw`, модели `.m3d`, сборка `.a3d`, спецификация и PNG для просмотра.

## Установка

Требования: Windows 10/11 x64, КОМПАС-3D v22 с SDK (папка `SDK` входит
в стандартную установку), .NET Framework 4.8.

1. Распаковать `kompas-mcp-1.0.0-win64.zip` в любую папку.
2. Сформировать interop-сборки КОМПАСа:
   ```
   powershell -ExecutionPolicy Bypass -File interop.ps1
   ```
   Скрипт находит КОМПАС по реестру и генерирует сборки из его библиотек типов
   (`SDK\lib\*.tlb`) утилитой TlbImp из Windows SDK. Если TlbImp нет — положите
   рядом с `KompasMcp.exe` interop-DLL из SDK КОМПАС: `Kompas6API5.dll`,
   `KompasAPI7.dll`, `Kompas6Constants.dll`, `Kompas6Constants3D.dll`
   (для «Давинчи» — ещё `KompasLibrary.dll` в папку `davinci`).
   Распространять эти DLL лицензия ASCON не разрешает, поэтому в архиве их нет.
3. Подключить сервер к MCP-клиенту (следующий раздел).

Если после переустановки КОМПАСа сервер сообщает `0x80040154` (класс не
зарегистрирован), один раз запустите КОМПАС вручную.

## Подключение к MCP-клиенту

**Claude Code:**
```
claude mcp add kompas -- C:/путь/KompasMcp.exe
```
В пути — прямые слэши: после `--` обратные слэши теряются. Проверка:
`claude mcp list` показывает `✔ Connected`.

**Claude Desktop** — `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "kompas": { "command": "C:\\путь\\KompasMcp.exe" }
  }
}
```

**Другие клиенты.** Сервер работает по stdio: построчный JSON-RPC 2.0
(по одному сообщению в строке, без LSP-заголовков). Методы: `initialize`,
`ping`, `tools/list`, `tools/call`. Проверка без клиента (из папки сервера;
в репозитории вместо `examples` — `tests`):
```
powershell -ExecutionPolicy Bypass -File examples\run_smoke.ps1 examples\smoke_3d.jsonl
```

## Сборка из исходников

Нужны КОМПАС-3D v22 и .NET Framework 4.8 (компилятор `csc.exe` есть в Windows).

```
powershell -ExecutionPolicy Bypass -File build.ps1      # → KompasMcp.exe
powershell -ExecutionPolicy Bypass -File package.ps1    # → dist\kompas-mcp-<версия>-win64.zip
```

`build.ps1` берёт interop-DLL из `lib\` или из папки уровнем выше, а если их
нет — вызывает `interop.ps1`. `package.ps1` собирает сервер, обновляет
справочник инструментов (`KompasMcp.exe --tools-md docs\tools.md`) и пакует
архив. Библиотека «Давинчи» собирается отдельно:
`davinci\build-native.ps1` (нужны ildasm, ilasm и rc из Windows SDK и Python).

Ключи командной строки: `--version`, `--tools-md [файл]`; для копилота —
`--attach`, `--rot-name <моникер>`, `--panel`.

## Копилот «Давинчи»

Библиотека `davinci\DavinciNative.rtw` подключается один раз через менеджер
приложений КОМПАСа (КОМПАС запоминает список) и добавляет меню «Давинчи»:

- **Панель** — окно чата. Сообщения уходят в `claude -p`, у которого этот
  сервер подключён в режиме attach: инструменты работают с открытым КОМПАСом
  пользователя, а не с отдельным скрытым экземпляром. Enter — отправить,
  Shift+Enter — новая строка; вложения копируются в `<workspace>\attach`;
  тёмная тема — кнопкой в шапке. Окно одно на систему: повторный вызов
  выводит его на передний план.
- **Диагностика** — моникер в ROT и путь к журналу.

Настройки — `davinci\davinci.json`:

| Ключ | Назначение |
|---|---|
| `kompasMcpExe` | путь к серверу; пусто — `KompasMcp.exe` уровнем выше библиотеки |
| `workspace` | рабочая папка `claude`; пусто — `mcp-out` рядом с сервером |
| `model` | модель `claude`; пусто — по умолчанию |
| `claudeCmd` | команда запуска, по умолчанию `claude.cmd` |
| `timeoutSec` | лимит на запрос, по умолчанию 900 с |
| `env` | дополнительные переменные окружения для `claude` (прокси, ключи) |

Отдельный вход не нужен: если `claude -p` работает в обычном терминале
пользователя, он работает и из панели — окружение пользователя доливается
из реестра. Если КОМПАС закрыли при открытой панели, сервер отвязывается
и переподключается к новому КОМПАСу автоматически.

## Тесты и сценарии

```
powershell -ExecutionPolicy Bypass -File tests\protocol_test.ps1     # протокол, без КОМПАСа
powershell -ExecutionPolicy Bypass -File tests\run_smoke.ps1 tests\smoke_gears3d.jsonl
```

Сценарии `tests\smoke_*.jsonl` — последовательности вызовов инструментов,
их удобно читать как рецепты:

| Сценарий | Что строит |
|---|---|
| `smoke_flange.jsonl` | чертёж фланца: виды, размеры, штриховка, штамп |
| `smoke_cut.jsonl` | линия разреза, цепочки размеров, DXF |
| `smoke_3d.jsonl` | втулка и фланцевая крышка, масса |
| `smoke_std.jsonl`, `smoke_std2.jsonl` | крепёж М6–М48, шпилька, штифты, подшипник |
| `smoke_gear.jsonl`, `smoke_gear_solid.jsonl` | чертёж цилиндрического колеса с диском и сплошного |
| `smoke_gear_pair.jsonl` | сборка цилиндрической пары |
| `smoke_gears.jsonl` | чертежи: коническое колесо, червяк, червячное колесо, цилиндрическое колесо, пружина |
| `smoke_gears3d.jsonl` | 3D: червяк, червячное и коническое колёса, сборки червячной и конической пар |
| `smoke_spring.jsonl`, `smoke_spring3d.jsonl` | пружины: чертёж, 3D сжатия и растяжения, подшипники 212/312 |
| `smoke_check.jsonl` | проверочные расчёты и чертёж пружины с диаграммой испытаний |
| `smoke_spec.jsonl` | спецификация ГОСТ 2.106 |
| `smoke_asm.jsonl` | узел (плита, болты, шайбы, гайки): сборка, сборочный чертёж, спецификация |

Копилот проверяется программами `tests\*_test.cs` (сборка — `build_*_test.ps1`):
разбор потока `claude`, сессия, панель, кодировка, вложения и сквозной
сценарий с живым КОМПАСом.

## Архитектура

```
src/Program.cs, Rpc.cs     точка входа, stdio-цикл, диспетчер JSON-RPC
src/ToolRegistry.cs        реестр инструментов, JSON-схемы, разбор аргументов
src/KompasHost.cs          жизненный цикл КОМПАСа, режим attach через ROT
src/tools/                 инструменты: 2D, 3D, передачи, пружины, крепёж,
                           проверки, спецификация, сборочный чертёж, DrawKit
src/gost/                  расчёты по ГОСТ без КОМПАСа: передачи, пружины,
                           крепёж, ЕСДП, материалы, прочность
src/davinci/, src/Ui/      копилот: запуск claude, сессия, панель чата
davinci/                   библиотека КОМПАСа «Давинчи» (.rtw)
```

- **Протокол** — построчный JSON-RPC в stdio; stdout занят только протоколом,
  диагностика — в `kompas-mcp.log` рядом с exe.
- **Инструмент** — имя, описание, JSON-схема и обработчик в `ToolRegistry`;
  ошибка выполнения (`ToolException`) уходит клиенту как `isError` с понятным
  текстом, а не как сбой протокола.
- **КОМПАС** — свой скрытый экземпляр на сервер (чужие не трогаются) или,
  в режиме attach, КОМПАС пользователя через моникер в ROT.
- **Расчёты** (`src/gost`) не зависят от КОМПАСа: те же функции дают
  геометрию чертежу и 3D-модели, поэтому они всегда согласованы.
- **Пути** — всегда абсолютные: КОМПАС считает относительные пути от своей
  рабочей папки, а не от папки сервера.
- Найденные особенности API КОМПАСа (направление спирали, оси размещения,
  единицы размеров и другие) собраны в [справочнике по классам](docs/classes.md#10-особенности-api-компас).

## Ограничения

- В 3D эвольвентный профиль — у цилиндрических колёс; у конических
  и червячных колёс профиль прямобочный 20° (для архимедова червяка он точный).
- Резьба не моделируется: крепёж — по номинальному диаметру.
- Спецификация — один лист А4 (до 25 строк).
- Сборочный чертёж: виды спереди, сверху и слева; точку-указатель позиции
  сервер выбирает по габаритам компонентов — на сложных сборках её стоит
  проверить.
- Проверочные расчёты упрощены (без учёта ресурса, коэффициенты нагрузки —
  оценочные) и подходят для эскизного проектирования.
- Проверено на КОМПАС-3D v22.

## Лицензия

Не определена: все права сохранены за автором. Interop-сборки ASCON
в репозиторий и архив не входят.
