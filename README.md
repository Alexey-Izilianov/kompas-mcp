# kompas-mcp — MCP-сервер автоматизации КОМПАС-3D

MCP-сервер (stdio, построчный JSON-RPC) с семантическими инструментами поверх
проверенных идиом API-5/API-7 КОМПАС-3D v22. Без внешних зависимостей: чистый C#
(сборка через csc.exe из .NET Framework 4). Позволяет любому MCP-клиенту
(Claude Code, Claude Desktop и др.) строить параметрические детали и чертежи
по ЕСКД одной фразой.

## Возможности (51 инструмент)

- **Инфраструктура**: `ping`, `kompas_status`, `kompas_start`, `kompas_show`,
  `kompas_stop`, `list_open_documents`, `kill_kompas`
- **2D-чертежи**: форматы A0–A4, виды, линии/дуги/окружности, размеры
  (линейные/диаметральные/радиальные/угловые), штриховка, шероховатость,
  основная надпись (штамп), техтребования, экспорт в PNG,
  композит `circle_array` (отверстия по окружности с осевыми крестами)
- **3D-детали**: эскизы на плоскостях (в т.ч. смещённых), выдавливание/вырезы,
  вращения, отверстия, фаски/скругления, массивы, массовые характеристики,
  рендер в PNG (работает даже в невидимом режиме)
- **Расчёты**: библиотека материалов, допуски и посадки ЕСДП (ГОСТ 25346/25347),
  моменты инерции сечений
- **Стандартные изделия** (`std_part`, генераторы по таблицам ГОСТ): болты
  ГОСТ 7805, гайки ГОСТ 5915, шайбы ГОСТ 11371, шариковые подшипники ГОСТ 8338
- **Зубчатые передачи**: эвольвентная геометрия ГОСТ 16532 (`gear_calc`,
  `gear_wheel` — 3D-колесо с эвольвентным профилем зуба; масса сходится с
  shoelace-прогнозом в пределах 0.08%)
- **Пружины**: расчёт по ГОСТ 13765 (`spring_calc`), 3D-модель через спираль +
  кинематическое выдавливание (`spring_create`)

## Быстрый старт

1. Соберите сервер ([Сборка](#сборка)) и подключите к клиенту
   ([Подключение к MCP-клиенту](#подключение-к-mcp-клиенту)).
2. Запросите у Claude то, что нужно построить, обычным языком:
   - «Нарисуй чертёж фланца Ø100 с центральной ступицей Ø45 и 6 отверстиями
     Ø8 на окружности Ø70»;
   - «Сделай втулку Ø60×40 из стали 45 и скажи массу»;
   - «Построй зубчатое колесо m=2, z=40, шириной 20, отверстием Ø20»;
   - «Рассчитай посадку H7/p6 для Ø30»;
   - «Сделай пружину: проволока Ø2, виток Ø14, 10 витков».
3. Артефакты появляются в `mcp-out\` рядом с exe (детали `.m3d`, чертежи
   `.cdw`, рендер `.png`).

## Сборка

Требуется установленный КОМПАС-3D v22 (SDK не обязателен — нужны только
interop-DLL) и .NET Framework 4 (csc.exe входит в Windows).

1. Скопируйте interop-DLL из поставки КОМПАС (`Kompas6API5.dll`, `KompasAPI7.dll`,
   `Kompas6Constants.dll`, `Kompas6Constants3D.dll`, `KAPITypes.dll`) в папку
   `lib\` рядом с `build.ps1` (либо рядом с `build.ps1` в корне репозитория —
   скрипт ищет оба места; DLL должны лежать рядом с exe после сборки, скрипт
   копирует их сам).
2. Сборка:
   ```
   powershell -ExecutionPolicy Bypass -File build.ps1    # → KompasMcp.exe
   ```
3. Проверка без клиента:
   ```
   powershell -ExecutionPolicy Bypass -File tests\protocol_test.ps1
   ```

## Подключение к MCP-клиенту

### Claude Code

```
claude mcp add kompas -- C:/путь/KompasMcp.exe
```

⚠️ `claude mcp add` с `--` съедает обратные слэши — используйте прямые
(`/`). Проверка: `claude mcp list` должно показать `✔ Connected`.

### Claude Desktop

`claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "kompas": {
      "command": "C:\\путь\\KompasMcp.exe"
    }
  }
}
```

### Другие MCP-клиенты

Сервер говорит по stdio: построчный JSON-RPC (не LSP-фрейминг). Достаточно
запустить `KompasMcp.exe` как дочерний процесс и общаться строками JSON.
Пример прямой проверки:

```
KompasMcp.exe < tests\smoke_3d.jsonl
```

## Smoke-сценарии

В `tests\` лежат готовые построчные JSON-RPC сценарии (аргументы вызовов —
готовый «рецепт» последовательности тулов):

| Сценарий | Что строит |
|---|---|
| `smoke_flange.jsonl` | чертёж фланца со штампом, размерами, штриховкой (36 вызовов) |
| `smoke_3d.jsonl` | 3D-детали: втулка, крышка фланцевая |
| `smoke_std.jsonl` | крепёж: болт, гайка, шайба, подшипник |
| `smoke_gear.jsonl` | зубчатые колёса m=2, z=20/40 |
| `smoke_spring.jsonl` | пружина d2/D14/n10 |

`tests\area_samples.ps1` — shoelace-прогноз массы эвольвентного профиля
(samples=1/3/6) для сверки с массой КОМПАСа; `tooth_thickness_check.ps1` —
проверка толщины зуба по окружности произвольного радиуса.

## Жизненный цикл КОМПАСа

- MCP держит СВОЙ экземпляр (`KOMPAS.Application.5`); каждый
  `Activator.CreateInstance` поднимает новый процесс KOMPAS.Exe, поэтому PID
  фиксируется дифференциальным снапшотом процессов.
- `kompas_start` (visible=false по умолчанию) → инструменты → `kompas_stop`.
- Чужие запущенные экземпляры КОМПАСа не затрагиваются.
- COM-классы регистрируются при первом запуске KOMPAS.Exe: если после
  переустановки КОМПАСа сервер пишет «0x80040154», один раз запустите
  КОМПАС вручную.

## Журнал и артефакты

`kompas-mcp.log` рядом с exe — все вызовы и ошибки (stdout занят протоколом).
Артефакты по умолчанию пишутся в `mcp-out\` рядом с exe. Относительные пути в
`save_part`/`open_part` разрешаются от текущей директории сервера —
предпочтительно передавать абсолютный путь.

## Планы

Проект развивается по фазам; каждый пункт оформляется как обычный инструмент
MCP с зашитыми идиомами API.

**Ближайшие шаги (2D-документация):**
- 2D-чертёж зубчатого колеса по ГОСТ 2.402: вид, таблица параметров
  (m, z, x, степень точности, межосевое), оформление под ЕСКД;
- сборка «пара колёс в зацеплении»: assembly-инструменты, контроль
  межосевого расстояния (для m=2, z=20/40 — 60 мм);
- пружины: чертёж по ГОСТ 2.401 (условное изображение + таблица параметров),
  пружины растяжения с витками под зацеп, корректная масса в момент создания
  (сейчас GetMass для кинематических тел отдаёт 0 до переоткрытия файла);
- расширение крепежа: винты, шпильки, подшипники других серий;
- групповые операции для 2D (композиты `dim_group`, `section_view`), чтобы
  полный чертёж собирался меньшим числом вызовов;
- экспорт чертежей в DXF.

**Дальше:**
- спецификации по ЕСКД (объекты СПС: «деталь», «стандартное изделие») с
  автоматическим заполнением из генераторов;
- детали-представители и упрощения для сборочных чертежей;
- конические и червячные передачи (расчёт + 3D);
- «Копилот»: собственная библиотека КОМПАСа (.rtw) с пунктом меню
  «Claude Assistant» и чат-панелью, которая гоняет headless-клиента
  (`claude -p`) с подключённым этим MCP-сервером — построение моделей прямо
  из диалога внутри КОМПАСа;
- прикладные проверки по ГОСТ (передаточные отношения, прочность зуба,
  жёсткость пружин) с выдачей отчёта в техтребования чертежа.
