# kompas-mcp 1.0.0 — справочник инструментов

Файл сформирован командой `KompasMcp.exe --tools-md docs\tools.md` из реестра сервера: описания и параметры совпадают с тем, что получает MCP-клиент в `tools/list`. Всего инструментов: 75.

Единицы: длины — мм, углы — градусы, силы — Н, моменты — Н·м, напряжения — МПа. Пути — абсолютные или относительно папки сервера; результаты по умолчанию — в `mcp-out` рядом с exe.

## Инфраструктура

### ping

Проверка связи с сервером. Не обращается к КОМПАСу.

Параметров нет.

### kompas_status

Статус экземпляра КОМПАС, удерживаемого MCP-сервером: запущен ли, PID, видимость, открытые документы. Не запускает КОМПАС.

Параметров нет.

### kompas_start

Запустить экземпляр КОМПАС-3D (MCP держит свой процесс). visible=false по умолчанию — окно скрыто, автоматизация работает. Повторный вызов безопасен. В attach-режиме (копилот) запрещён.

| Параметр | Тип | Обяз. | Описание |
|---|---|---|---|
| `visible` | boolean |  | Показать окно КОМПАСа (по умолчанию false) |

### kompas_show

Показать/скрыть окно КОМПАСа, запущенного MCP-сервером. В attach-режиме (копилот) запрещён — окно КОМПАСа юзера не изменяется.

| Параметр | Тип | Обяз. | Описание |
|---|---|---|---|
| `visible` | boolean | да | true = показать, false = скрыть |

### kompas_stop

Полностью закрыть экземпляр КОМПАС, запущенный MCP-сервером (несохранённые изменения теряются). Чужие экземпляры КОМПАСа не трогаются. В attach-режиме (копилот) только отсоединяется от КОМПАСа юзера, не закрывая его.

Параметров нет.

### list_open_documents

Список открытых документов в экземпляре КОМПАС, удерживаемом MCP (имя и путь).

Параметров нет.

## Сборочный чертёж

### assembly_drawing

Сборочный чертёж по файлу сборки .a3d (ГОСТ 2.109): ассоциативные виды в проекционной связи (front — главный, top — под ним, left — справа), без невидимых линий, габаритные размеры, позиции линиями-выносками (одинаковые компоненты — одна позиция), технические требования, штамп; спецификация ГОСТ 2.106 тем же списком позиций (spec=false — без неё). Масштаб подбирается по листу А3.

| Параметр | Тип | Обяз. | Описание |
|---|---|---|---|
| `assembly` | string | да | Путь к сборке .a3d |
| `views` | array of string |  | Виды, первый всегда front (по умолчанию [front, top]) |
| `scale` | number |  | Масштаб (по умолчанию — наибольший стандартный, при котором виды помещаются) |
| `name` | string |  | Наименование изделия (по умолчанию — имя сборки) |
| `designation` | string |  | Обозначение изделия; к чертежу добавляется «СБ» |
| `tech` | array of string |  | Технические требования |
| `spec` | boolean |  | Сформировать спецификацию (по умолчанию true) |
| `path` | string |  | Путь .cdw (по умолчанию <сборка>_sb.cdw) |
| `png` | string |  | PNG-рендер чертежа (спецификация — рядом с суффиксом _spec) |
